PROPOSED SOLUTION DESIGN

pullydragged Platform

Live Chariot Tracking Platform for Rath Yatra Festivals (Itahari & Biratnagar MVP)

🌟 Executive Summary

pullydragged is a modern, real-time web application that connects festival attendees directly to the live position of the sacred Rath (Chariot) during Rath Yatra. Designed as a reusable global template, the platform provides devotees with an auto-centering live map, route progress tracking, and interactive checkpoint cards (photos, history, and live announcements).

🏛️ High-Level System Architecture

📱 1. Devotee Mobile App

Public-facing web app built with Next.js & Leaflet.js. Renders an auto-centering map and dynamic progress bar with zero registration required.

📡 2. GPS Broadcaster

Single-tap web app running on the dedicated smartphone attached to the chariot. Uses Screen WakeLock and offline retry buffers to ensure 99.5%+ uptime.

⚡ 3. Real-Time Socket Engine

Socket.io WebSocket server broadcasting sub-second location updates to isolated event rooms (event:itahari, event:biratnagar).

🛠️ Core Technology Stack

  • Frontend Framework: Next.js 14 (App Router) + React 18
  • Styling & UI: Tailwind CSS v4 (CSS-first engine)
  • Interactive Map: Leaflet.js + OpenStreetMap (No API limits)
  • Real-Time Pipeline: Socket.io WebSockets
  • Database: MongoDB Atlas (Mongoose ODM)
  • Geo Math Engine: Turf.js (Nearest polyline projection for route progress)
