# pullydragged
A Chariot Tracking web-app for upcoming "Rath Yatra" or chariot festival. The chariot will be dragged around in a location by swarm of people. It will go through a certain route and will rest on certain points. Our website displays the current location of the chariot with it's progress. As the chariot moves, progress bar shaped like the route starts to get filled as well. When reached to the checkpoints, information about that location is also displayed in the website.
